# Demo clips

Drop your screen recordings in this folder. The /demo page already points at these exact file names:

| File | What it should show |
| --- | --- |
| `clip1.mp4` | Paste what someone said, tap Read tastes, and the likes and avoids appear as chips |
| `clip2.mp4` | Attach a screenshot of a chat and watch it turn into chips |
| `clip3.mp4` | Turn chips on and off and watch the Predictive inference rewrite itself |
| `clip4.mp4` | Switch the occasion, see the place with its map pin, the gift brand and the backup plan |

Tips

- MP4 (H.264) plays everywhere. Keep each clip under about 25 MB and 60 seconds.
- 16:9 works best (for example 1280 by 720).
- Until a file exists, the page shows a tidy "Clip coming soon" card in its place. Nothing else to change.
- Do not record real people's private messages. Use the built-in example text.
